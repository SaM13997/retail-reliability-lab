# Retail Reliability Lab

A portfolio-quality frontend systems lab for real-world unattended retail operations.

The lab demonstrates production-minded React and React Native engineering through two focused demos:

- **Operator Console** — data-rich, real-time web workflows for multi-location operations.
- **Store POS** — resilient React Native checkout flows for unattended stores.

It also includes shared typed domain logic, automated tests, architecture notes, and original engineering articles.

> This is an independent demo using generated data. It is not affiliated with any retailer or employer.
