# Acceptance criteria

A deliverable is complete only when:

- Fresh-clone setup is documented and works with supported Node/npm versions.
- Operator Console passes typecheck, lint, unit tests, production build, and Cypress smoke tests.
- Store POS passes typecheck, tests, and Expo web export.
- Shared domain package has focused unit tests for edge cases.
- CI runs all practical quality gates.
- Generated demo data and independent-project disclaimer are visible.
- Each article links to real source files and avoids unsupported performance claims.
- Root README includes architecture, screenshots or demo GIF placeholders only if clearly labeled, commands, tradeoffs, and project map.
- No secrets, copied employer UI, dead controls, unexplained TODOs, or fabricated production metrics.
